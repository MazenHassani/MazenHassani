# Hi, I'm Mazen 👋

**I build things, teach what I learn, and make videos of the interesting parts.**

I've built competition robots with teammates, won at the Engineering Design Challenge in Beirut, and reached the World Robot Olympiad finals in Thailand. Electronics, software, computer vision: I enjoy bringing the pieces together.

Today, I work on backend engineering and AI enablement at **Bruker**. Here's some of the work behind that path.
